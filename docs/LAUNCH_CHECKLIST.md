## Details

**1. OpenRouteService.** Sign up at https://openrouteservice.org/dev/#/signup, create a token (Standard plan). Optimisation and directions are both included in the free plan.

**3. Google.** Google Cloud Console → APIs & Services → OAuth consent screen (external, app name, support email, privacy policy URL) → Credentials → Create OAuth client ID → _Web application_. Authorised redirect URIs: `https://<project-ref>.supabase.co/auth/v1/callback` and, for local testing, `http://127.0.0.1:54321/auth/v1/callback`. Paste the client id/secret into Supabase, then set `EXPO_PUBLIC_AUTH_PROVIDERS=google` (or `google,apple`).

**4. Apple.** developer.apple.com → Identifiers: App ID for the bundle id with _Sign in with Apple_ enabled; a _Services ID_ (e.g. `com.travelist.app.web`) with the return URL `https://<project-ref>.supabase.co/auth/v1/callback`; Keys → new key with Sign in with Apple → download the `.p8`. In Supabase → Apple provider enter the Services ID and bundle id (comma-separated) and the secret generated from the key (Supabase docs include a generator; it expires every 6 months).

**Hosted deploy** once 2 is done: see README → "Deploying (hosted)".
